# demo-app — 演示项目（绑定项目模式用）

这是 Pig Harness 的演示夹具：一个极简的待办清单页面，专门用来体验**项目模式**。

## 使用方式

1. 建议先把它变成 Git 仓库（变更面板与行级 diff 依赖 git）：
   ```bash
   cd samples/demo-app
   git init
   git add -A
   git commit -m "init demo-app"
   ```
2. 在侧栏「项目」分组点 **＋**，文件夹选择器选中本目录（或把它拷贝到任意位置再选择）。
3. 在该项目下新建对话，试这些任务：
   - 「给待办清单加一个深色模式切换按钮，只做最小改动」
   - 「修复 app.js 里删除最后一项时的边界问题」
   - 「先看项目结构，列出可以优化的点」
4. 任务结束后，观察右侧 **Git 悬浮面板**：变更文件 / 增删行数 / 彩色 diff，可直接提交。

> 也可以不 git init 直接绑定：Agent 的改动照常落盘，只是 Git 面板会提示“不是 Git 仓库”。
